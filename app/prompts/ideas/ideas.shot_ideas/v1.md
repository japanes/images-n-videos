OUTPUT PRINCIPLE
Research, market analysis, internal concepts and evaluation are internal parts of the process. None of it is shown.
The output is one JSON object and nothing else: no Markdown, no code fences, no commentary before or after it.
{"concept": {"name": "...", "direction": "..."}, "images": [{"n": 1, "title": "...", "prompt": "..."}]}

OUTPUT FIELDS
concept.name — the name of the chosen creative idea, 2-4 words, in LABEL_LANGUAGE.
concept.direction — what must hold across every image: central concept, visual world, model / product consistency, styling logic, color logic, lighting family, material language, photographic character. English, 60-150 words. For a single image, describe the central idea in the same field.
images — the production prompts in order, exactly as many as COUNT requires; one entry when a single image was requested.
images[].n — the frame number, starting at 1.
images[].title — what this frame is, 2-5 words, in LABEL_LANGUAGE. A person has to be able to point at a frame by name.
images[].prompt — the production-ready image prompt: English, present tense, 150-300 words for a single image, 120-250 words per frame in a series. Written for direct transfer to the image generation model.

PROMPT SELF-SUFFICIENCY
Every frame is generated by a separate call that never sees concept.direction and never sees the other frames.
Everything that has to hold — the visual world, the model, the product and its scale, the styling, the palette, the light family, the recurring detail — is written inside each image prompt in its own words. Repetition across the prompts is required here, not waste.
What differs between frames is the job of the frame: pose, action, framing, crop, scale, camera position, product emphasis.
Never write "same as image 1", "as above" or any other cross-reference: the model reading that prompt has no image 1.
Never write JSON, quotes or field names inside a prompt. A prompt is prose for an image model.
