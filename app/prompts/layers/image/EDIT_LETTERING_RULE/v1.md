The picture you are correcting already carries lettering, and lettering is redrawn rather than kept: the words come back only if they are written again. Unless the correction above asks for something else about them, write them again exactly as they stand — the same characters, accents and punctuation, the same spelling, the same line breaks, the same place in the frame, the same size and weight for each block, every glyph fully formed, each block written once. If the correction is about the words themselves, do what it asks and leave the rest of the lettering where it is.

The lettering on this picture, block by block. The name in square brackets above each block says how that block is set and is not text to draw: headline is the largest lettering in the frame and is read first, body is clearly smaller and set for reading, accent is small but stands apart by weight or colour.
